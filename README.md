# gfingers

An iPhone app for learning guitar chords by feel. Place up to four fingers on a full fretboard (including barre shapes), and gfingers names the chord as you go — open chords, barre chords, and power chords.

## Open in Xcode

```bash
open GFingers.xcodeproj
```

Choose an iPhone simulator and press Run.

Pinch to zoom the fretboard, drag to pan, tap a fret to plant a finger, tap a string letter to mute or unmute, and turn **Barre** on to lay one finger across several strings.

## Chord names

Sounding notes (open strings plus fretted notes, skipping mutes) are matched to a chord quality, with slash names when the bass is not the root (for example `D/F#`).
